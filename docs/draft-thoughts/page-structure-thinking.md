| -------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Setup**      | Define the question and provide the starting material   | Creates the project input set required to begin Knowledge construction. The user enters the original Business Question, selects a foundational knowledge pack and uploads the relevant documents and data files. The user may add a short description or purpose for each source. The system checks whether the files can be read and then starts the Knowledge analysis.                                                                                                                                                                                   | **Business Question** — enter the verbatim question that the files should support; **Foundational knowledge** — select the applicable domain pack and version; **Sources** — upload documents, spreadsheets or other supported files; **Source context** — optionally describe what each source contains or why it matters; **Input status** — show successfully read, failed or unsupported sources; **Review and start** — show the complete input set and begin Knowledge construction                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Knowledge**  | Build and confirm the knowledge needed for the question | Analyses the Business Question, foundational pack and uploaded sources together. The system proposes the structured interpretation of the question and the local organisational knowledge required. It asks focused questions where definitions, mappings, rules or authority remain unclear. The user can answer, select an alternative, correct a proposal, defer it or mark it unknown. After resolving or explicitly accepting the open items, the user reviews the combined knowledge, makes limited manual corrections and saves a Knowledge version. | **Input summary** — Business Question, foundational pack and source versions used for this draft; **Proposed interpretation** — generated `answer_type`, `requested_output` and `scope`; **Proposed local knowledge** — inferred concepts, source mappings, definitions, dependencies and organisational rules; **Questions** — unresolved Guide decisions with reason, scope, alternatives and supporting source reference; **Answer question** — confirm, correct, choose a candidate, defer or mark unknown; **Conflicts and limitations** — competing interpretations and unresolved knowledge that will remain visible; **Knowledge review** — combined foundational, source-derived and human-confirmed knowledge with provenance; **Knowledge editor** — add or correct individual draft entries without exposing internal claim mechanics; **Save Knowledge version** — create the version used by the assessment; **Revise Knowledge** — reopen the current version as a successor draft after a changed answer or source                                                                                                                                     |
| **Assessment** | Test whether the available data supports the answer     | Uses the selected Knowledge version and source set to derive what must be supported, execute checks and produce readiness. The user reviews the proposed dependencies, starts the run and inspects the result. When a gap is caused by an incorrect answer, missing source or changed file, the user updates the relevant input and reruns only the affected work. Previous runs remain available for comparison.                                                                                                                                           | **Assessment setup** — show Business Question, validated interpretation, Knowledge version and selected source versions; **Dependency review** — list what the answer requires and allow confirmation before running; **Run assessment** — execute profiling, proposals, checks, clarification and readiness stages; **Run status** — show the current stage and failures without requiring an audit-event system; **Readiness summary** — display `ready`, `ready_with_limitations` or `blocked`, with dependency counts rather than a percentage; **Open gaps** — show unresolved, contradicted, stale or waived dependencies; **Assessment questions** — questions created from the actual assessment findings, kept separate from Knowledge questions; **Resolve gap** — answer a question, choose a mapping, upload a replacement source, revise the Business Question or return to Knowledge; **Staleness impact** — show what became stale after a source or question changed; **Rerun affected work** — replay the stages permitted by M7 and explain what was reused; **Compare runs** — show the previous and current verdict and which dependencies changed |
| **Report**     | Present the current readiness result                    | Presents the Business Question, its validated interpretation, Knowledge version, source versions, readiness verdict, supporting evidence and unresolved limitations. The POC does not require formal publishing governance or a complete report library. The user can regenerate the report after a rerun and optionally export it.                                                                                                                                                                                                                         | **Readiness overview** — Business Question, requested output and verdict; **Input basis** — Knowledge version and source versions used; **Dependency result** — supported, limited and blocking items in business language; **Evidence detail** — source, sheet, column, document page, quote, check result or human confirmation; **Limitations** — unresolved assumptions, deferred questions and accepted unknowns; **Run comparison** — concise change from the previous run; **Regenerate report** — rebuild after a revised source, answer or Knowledge version; **Export** — optional HTML or PDF output                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
